# Project COGO ☕️
### 한 잔의 커피, 무한한 성장
'커피 한 잔의 대화'를 통해 숭실대학교 재학생들이 진로, 복수전공, 대외활동 등 다양한 고민을 편안하게 나누고 성장을 돕는 네트워킹 플랫폼입니다.

#### COGO가 무엇인가요?
COGO는 'COFFEE'와 'GO'의 알파벳을 조합한 단어로, 멘토와 멘티가 커피 한 잔☕의 짧은 만남을 통해 함께 성장할 수 있도록 돕는 서비스에요.
COGO는 학교 안에서 관계를 맺는 방식에 대한 새로운 패러다임을 제안해요. 바로 카페에서의 가벼운 만남, 커피챗의 형태로 말이죠.

#### COGO는 어떤 활동을 하나요?
후배와의 교류를 원하는 선배와, 학교생활이 막막한 후배를 일대일 매칭하여 커피챗을 진행해요.
COGO와 함께라면 같은 학과, 같은 동아리가 아니어도 관계를 맺을 수 있어요. '숭실대'라는 공통분모 안에서 다양한 경험을 가진 사람들을 만나보세요😊
